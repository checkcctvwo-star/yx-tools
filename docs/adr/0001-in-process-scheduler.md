# 内置调度器替代系统 crontab

定时测速最初通过写系统 crontab 实现（`yx cron` 往 crontab 里登记命令行任务）。为让定时功能在 Docker / 飞牛 NAS 等没有可用 crontab 的环境里正常工作，改为程序内置调度器：任务列表持久化在 `yx-config.json` 的 `schedules` 字段，进程内每分钟检查到期任务，复用与手动测速同一个 Runner 串行执行。页面上的定时任务弹窗同步改为管理这批内置任务，CLI 的 `yx cron` 保留不动。

## Considered Options

- **系统 crontab**：宿主机上现成、进程退出也能跑，但容器里 `crontab` 常常装不了或用不了（非 root 无 suid 位），任务参数被冻结成命令字符串，改参数要重写命令。
- **内置调度器**：跨环境可用、任务结构可配置（来源、参数、上报开关都是结构化快照）、重启后靠落盘配置续跑；代价是进程退出期间不执行，且错过的时间点只在重启后的下一个检查周期补跑一次。
- 二者并存：维护两套 UI 与两套语义，收益低于复杂度，不做。

## Consequences

- 页面定时任务不再依赖 `CronSupported()`，Docker 镜像里功能完整可用。
- 调度与手动测速共享 Runner，天然串行：到点时已有任务在跑则跳过并记日志。
- 定时任务的上报目标改为独立开关（GitHub / Worker 可同时开），替代旧命令行里二选一的 `-upload` 语义。
